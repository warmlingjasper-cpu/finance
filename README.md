Finance — Personal Finance Manager

A personal finance management application built with Django REST Framework and React, designed to help users organize their finances, monitor expenses, track income, and manage investments.

The project aims to provide a simple and intuitive way to understand financial activity and make better financial decisions.

Features

Financial Management
Dashboard: Overview of personal financial activity.
Income Management: Register and track income.
Expense Management: Organize and monitor expenses.
Investments: Manage investment records.
Funds: Organize financial funds and allocations.
Financial Planning: Plan and organize future financial goals, budgets, and allocations.
Financial Overview: Monitor planned amounts and compare them with actual financial activity.

Other Features

REST API: Backend architecture built with Django REST Framework.
Responsive Interface: Frontend developed with React
